# Тренировки

Проект по тренировкам. Актуальный план — в [plan-trenirovok.md](plan-trenirovok.md), всегда сверяться с ним перед советами.

## Контекст

- 6 дней в неделю: пн/ср/пт силовые, вт/чт/сб кардио (велотренажёр, иногда гребной), вс отдых.
- Цель — здоровье и поддержание формы, не соревнования, без гонки за весами.
- Приоритет по группам мышц: спина чуть выше остальных.
- Зал коммерческий, оборудование ограничено списком в плане.
- Скамья одна на весь зал и часто занята — избегать упражнений, которые её требуют.
- Подтягивания не делать.
- Дома есть резинки.

## Как отвечать

- По-русски, без лишних вступлений.
- Новые упражнения — только простые по технике, с описанием: целевые мышцы, техника, частые ошибки.
- Замену упражнения — сначала самый простой вариант, потом альтернативы.
- Не усложнять программу без запроса.

## Веб-трекер тренировок

[index.html](index.html) — мобильная страница: показывает тренировку на сегодня по дню недели (пн/ср/пт силовая A/B, вт/чт/сб кардио, вс отдых), даёт отмечать упражнения выполненными, чередует силовые комплексы A/B (если в прошлый раз отмечено хотя бы одно упражнение — переключает, если нет — повторяет тот же). Опубликован как Claude Artifact.

Синхронизация между открытиями (в т.ч. с телефона) идёт через собственную инфраструктуру в Yandex Cloud, не через localStorage:
- Cloud Function `workout-sync` (id `d4eqqcsovv5r9co1cab2`, публичный URL `https://functions.yandexcloud.net/d4eqqcsovv5r9co1cab2`) — GET отдаёт состояние, PUT сохраняет. Анонимный вызов разрешён (`allow-unauthenticated-invoke`).
- Функция сама подписывает запросы к Object Storage секретным ключом, который лежит в Yandex Lockbox (`workout-sync-s3-keys`), а не в коде страницы — на странице секретов нет вообще.
- Данные хранятся в бакете `alexs-workout-tracker`, объект `workout/state.json`. У бакета есть policy на анонимный доступ к этому объекту, но платформа Yandex не поддерживает анонимную запись (PutObject) — поэтому запись идёт только через функцию, а не напрямую со страницы.
- Сервис-аккаунт `workout-sync-sa` (id `ajeoq0c1odoir4h5bqi6`) даёт функции право читать секрет из Lockbox (роль `lockbox.payloadViewer`).

Если нужно поменять логику страницы — редактируй `index.html` и переопубликовывай через Artifact тем же путём к файлу (URL останется прежним). Если нужно поменять серверную логику — код функции лежит только в Yandex Cloud (деплоился из временной директории в этой сессии), при следующем изменении проще всего пересоздать `index.py` заново и задеплоить `yc serverless function version create`.
