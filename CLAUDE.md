# Тренировки

Проект по тренировкам. Актуальный план — в [plan-trenirovok.md](plan-trenirovok.md), всегда сверяться с ним перед советами.

## Контекст

- 6 дней в неделю: пн/ср/пт силовые, вт/чт/сб кардио (велотренажёр, иногда гребной), вс отдых.
- Цель — здоровье и поддержание формы, не соревнования, без гонки за весами.
- Приоритет по группам мышц: спина чуть выше остальных.
- Зал коммерческий, оборудование ограничено списком в плане.
- Скамья одна на весь зал и часто занята — избегать упражнений, которые её требуют.
- Подтягивания не делать.
- Дома есть резинки.

## Как отвечать

- По-русски, без лишних вступлений.
- Новые упражнения — только простые по технике, с описанием: целевые мышцы, техника, частые ошибки.
- Замену упражнения — сначала самый простой вариант, потом альтернативы.
- Не усложнять программу без запроса.

## Веб-трекер тренировок

[index.html](index.html) — мобильная страница: показывает тренировку на сегодня по дню недели (пн/ср/пт силовая A/B, вт/чт/сб кардио, вс отдых), даёт отмечать упражнения выполненными, чередует силовые комплексы A/B (если в прошлый раз отмечено хотя бы одно упражнение — переключает, если нет — повторяет тот же).

В силовой день есть кнопка «Переключить на комплекс A/B» — ручная правка на случай, когда трекер разошёлся с реальностью (тренировался без телефона, забыл отметить). Отметки другого комплекса при переключении не стираются, так что случайное нажатие ничего не теряет. В кардио и выходной кнопка скрыта.

Развёрнута на GitHub Pages: **https://alexsingle.github.io/workout/**. Репозиторий публичный (Pages всегда публичен, даже на приватном репо — приватность репо не спасла бы). Также есть копия как Claude Artifact.

### Ключ доступа

Страница открыта всем, но данные — нет. Синхронизация требует секретного ключа, который передаётся в якоре ссылки: `https://alexsingle.github.io/workout/#k=КЛЮЧ`. Якорь не уходит на сервер GitHub и не попадает в Referer. При первом открытии ключ сохраняется в localStorage, дальше страница работает и без якоря.

**Значение ключа НЕ хранится в этом репозитории** (он публичный) — только в Yandex Lockbox, секрет `workout-sync-access-key`. Посмотреть: `yc lockbox payload get --name workout-sync-access-key`. Без ключа страница работает, но сохраняет прогресс только на текущем устройстве.

Синхронизация между открытиями (в т.ч. с телефона) идёт через собственную инфраструктуру в Yandex Cloud, не через localStorage:
- Cloud Function `workout-sync` (id `d4eqqcsovv5r9co1cab2`, публичный URL `https://functions.yandexcloud.net/d4eqqcsovv5r9co1cab2`) — GET отдаёт состояние, PUT сохраняет. Анонимный вызов разрешён (`allow-unauthenticated-invoke`), но функция требует заголовок `X-Workout-Key` с тем самым ключом, иначе 401.
- Функция сама подписывает запросы к Object Storage секретным ключом, который лежит в Yandex Lockbox (`workout-sync-s3-keys`), а не в коде страницы — на странице секретов нет вообще.
- Данные хранятся в бакете `alexs-workout-tracker`, объект `workout/state.json`. Анонимный доступ к бакету закрыт (`anonymous_access_flags.read=false`) — единственный путь к данным идёт через функцию с ключом. Анонимную запись платформа Yandex не поддерживает в принципе, независимо от policy.
- Сервис-аккаунт `workout-sync-sa` (id `ajeoq0c1odoir4h5bqi6`) даёт функции право читать секреты из Lockbox (роль `lockbox.payloadViewer`).

`index.html` — самостоятельный HTML-документ (свои `<!DOCTYPE>`, `<head>` с `viewport`, `<body>`). Это важно: пока страница жила артефактом, claude.ai подставлял `<head>` сам, и без него Safari верстал страницу в 980px и уменьшал — мелкий текст в узкой колонке. Иконка домашнего экрана — `icon-180.png`, генерится скриптом на System.Drawing (в истории сессии), 180×180.

Если нужно поменять логику страницы — редактируй `index.html`, коммить и пуш: GitHub Pages пересоберётся сам за минуту-две. Если нужно поменять серверную логику — код функции лежит только в Yandex Cloud (деплоился из временной директории), проще всего пересоздать `index.py` заново и задеплоить `yc serverless function version create`.

При смене ключа доступа нужно обновить и Lockbox-секрет (новая версия `workout-sync-access-key`), и передеплоить функцию, чтобы она подхватила новую версию секрета.
